# Zearo MVP 设计规格

## 目标与成功标准

Zearo 是一个 Edge Manifest V3 扩展。用户在 `leetcode.cn` 或 `leetcode.com` 的公开题“题目描述”页面打开侧边栏并点击“开始解题”，扩展读取题目标题、正文和当前编辑器语言，调用用户配置的 OpenAI Chat Completions 兼容接口，并展示结构化中文讲解和对应语言代码。

完成标准：扩展可在 Edge 以解压缩方式加载；双站各至少三道公开题通过；设置、语言切换、模型请求、结构化渲染、复制代码和重新生成可用；约定的错误路径均快速失败并显示具体错误；权限、窄栏布局、键盘焦点及减少动态效果符合规格。

## 范围

首版只支持 `https://leetcode.cn/problems/<slug>/description/` 与 `https://leetcode.com/problems/<slug>/description/` 中可直接访问的公开题。支持 Python 3、Java、C++、JavaScript、TypeScript、Go、Rust。

不支持付费题、竞赛题、题解或提交记录页面；不读取用户代码，不自动写入编辑器，不运行或提交，不保存解题历史，不提供多轮对话或流式输出。

## 架构

采用原生 HTML、CSS、JavaScript，无框架、构建工具和第三方运行时依赖：

- `manifest.json` 声明侧边栏、存储、静态内容脚本和可选 API 域名权限。
- `service-worker.js` 让工具栏图标直接打开侧边栏。
- `content.js` 在用户点击开始时读取当前页面，不监听路由、不轮询、不使用 GraphQL。
- 侧边栏负责设置、请求模型、校验返回 JSON、展示答案和复制代码。

必需权限为 `sidePanel` 与 `storage`。LeetCode 内容脚本只匹配双站。用户保存 API 地址时逐域请求可选权限；远程地址仅允许 HTTPS，本机额外允许 `http://localhost` 和 `http://127.0.0.1`。保存新地址后移除旧域名权限。

## 数据流

1. 用户点击 Edge 工具栏图标打开 Zearo 侧边栏。
2. 首次使用填写 Base URL、API Key、模型名；侧边栏验证边界并请求对应域名权限。
3. 用户点击“开始解题”。侧边栏向当前标签页的内容脚本请求题目数据。
4. 内容脚本验证页面路径，读取题目标题、正文和 `#editor` 中的当前语言；任一关键内容缺失即明确报错。
5. 侧边栏使用自动识别或用户手动选择的语言，向 `<Base URL>/v1/chat/completions` 发出一次非流式请求。
6. 模型必须返回包含 `idea`、`steps`、`timeComplexity`、`spaceComplexity`、`code`、`pitfalls` 的 JSON。解析或字段校验失败即报错，不修复、不展示原始回答。
7. 合法结果按“思路、步骤、复杂度、代码、易错点”展示；重新生成会重新读取当前题并替换旧答案。

## 错误处理

只在用户输入、浏览器权限、页面 DOM、网络与外部 API 边界校验。非法地址、权限拒绝、非题目页、正文缺失、语言无法识别、网络失败、非 2xx 和无效 JSON 均显示具体错误，不静默回退或吞掉异常。

HTTP 错误显示状态码及经过长度限制的服务错误消息。API Key 不写入界面错误或日志。请求期间禁用重复请求。

## 视觉与交互

界面定位为“算法工作台”，不是聊天窗口。配色为纸白 `#F5F7FA`、石墨黑 `#18202A`、路径蓝 `#2855D9`、状态琥珀 `#D88A12`、边线灰 `#D9DEE7`。标题使用 Bahnschrift，中文正文使用 Microsoft YaHei UI，代码与复杂度使用 Cascadia Mono，并提供系统字体回退。

顶部为品牌、当前题目、语言选择和设置入口；主体沿一条“推演轨道”依序排列答案模块。唯一强调动效是请求期间轨道逐段点亮；系统启用减少动态效果时保持静止。窄侧栏不得横向溢出，所有交互控件必须有清晰键盘焦点。

扩展图标采用原创几何 Z 最短路径标记，只生成运行必需的尺寸。

## 验证

- 检查 Manifest V3 结构、权限与资源引用。
- 对题目路径、DOM 提取、7 种语言映射、URL 边界和响应 JSON 契约做自动化逻辑测试。
- 使用本地 OpenAI 兼容模拟端点验证成功、非 2xx、无效 JSON 和网络失败路径。
- 在 Edge 中验证侧边栏打开、动态权限、双站各三题、复制和重新生成。
- 在窄宽度、键盘操作与减少动态效果设置下检查界面。

若没有真实 API 凭据，只能将真实模型调用标记为待用户验证，不得宣称已通过。
