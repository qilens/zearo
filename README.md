# Zearo

Zearo 是一个用于 LeetCode 公开题学习的 Edge 侧边栏扩展。它读取题目描述和当前编辑器语言，通过用户配置的 OpenAI Chat Completions 兼容接口生成结构化中文讲解。

## 本地加载

1. 在 Edge 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本项目目录。
4. 打开 `leetcode.cn` 或 `leetcode.com` 的公开题“题目描述”页面。
5. 点击 Zearo 图标，配置 API 后开始解题。

Base URL 只填写协议、域名和端口，例如 `https://api.openai.com` 或 `http://localhost:1234`。Zearo 会请求 `POST <Base URL>/v1/chat/completions`。

## MVP 边界

- 支持 Python 3、Java、C++、JavaScript、TypeScript、Go、Rust。
- 设置中可选择 OJ 快捷模式或标准独立编译模式；默认使用 OJ 快捷模式。
- 最多缓存最近使用的 100 份完整解答；相同站点、题目、语言、代码模式、API 地址和模型会直接复用缓存。
- 完整解答后可进行一次性追问；新追问替换旧追问，且追问不写入缓存。
- 不读取或修改编辑器代码，不运行或提交答案，不保存解题历史。
- 支持公开题的裸题目路径和“题目描述”路径；不支持付费题、竞赛题及其他标签页。
- 扩展更新或标签页恢复后若内容脚本缺失，Zearo 会在当前 LeetCode 页面补注入并重试一次，无需刷新页面。

## 验证

运行自动化检查：

```powershell
node tests/core.test.js
```

Edge 手工验收：

1. 按“本地加载”步骤加载扩展，点击工具栏图标，确认侧边栏打开。
2. 保存 HTTPS 或本机 API 地址，确认 Edge 只请求该 API 域名的访问权限。
3. 在 `leetcode.cn` 和 `leetcode.com` 各打开至少三道公开题的“题目描述”页。
4. 保持“跟随编辑器”并切换 LeetCode 编辑器语言，确认生成代码语言一致；再逐一手动选择七种支持语言。
5. 确认等待期间无法重复开始，结果能展示思路、步骤、复杂度、代码和易错点，且复制代码与重新生成可用。
6. 确认首次开始会复用匹配缓存，重新生成会覆盖缓存；切换语言、模式、模型或站点后不错误复用。
7. 确认追问包含当前解答上下文，再次追问替换上次结果；重新生成后旧追问消失。
8. 分别检查非题目页、API 非 2xx、无效 JSON 和断网错误均显示具体原因。
9. 缩窄侧边栏并用键盘遍历控件，确认没有横向溢出且焦点清晰；开启系统“减少动画”后确认分析轨道不再循环。
